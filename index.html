Как получены эти данные?⌄

Браузер запрашивает погоду у нашего Python-сервера. Сервер обращается к WeatherAPI.com, получает JSON и передаёт его странице. API-ключ хранится только на сервере.

  1. 1Браузер → наш серверОжидает запроса
    GET/api/weather?city=Белгород

    Этот запрос виден в браузере: F12 → Network → Fetch/XHR.

  2. 2Наш сервер → WeatherAPI.comОжидает запроса
    GEThttps://api.weatherapi.com/v1/current.json?key=***&q=Белгород&lang=ru

    Внешний запрос выполняет Python. Его можно увидеть в терминале сервера. Ключ в этой записи скрыт.

  3. 3Полученный JSON → данные на странице

    После запроса здесь появятся реальные значения полей ответа.

Исходный ответ WeatherAPI.com
Сначала запросите погоду — здесь появится JSON-ответ внешнего сервиса.

Адрес `/v1/current.json`, параметры `key`, `q`, `lang` и имена полей описаны в документации WeatherAPI.com ↗.
